读书笔记 异常处理的设计与重构

发表于 2020-04-05 更新于 2026-07-30 分类于 学习
本文字数： 1.2k 阅读时长 ≈ 1 分钟

异常定义

  • fault（缺陷）

设计缺陷：代码错误。

组件缺陷：组件无法提供功能，包括物理缺陷和交互缺陷。

例：HTTP 200，return code 0，返回具体错误原因。

  • error（错误）

例：HTTP 520，接口内部错误。

  • failure（失败）

例：HTTP 520，return code 非 0，无法提供正常功能。

  • exception（异常）

程序语言中传递缺陷、错误、失败的对象。

函数不返回 null

  • 返回 “”、List、null object 代替。

缺陷处理

  • 避免缺陷（提前校验）
  • 缺陷容忍（使用备用方案）
  • 缺陷移除（修复错误状态）
  • 缺陷预测（检测软件质量）

使用 try-with-resources 自动清理资源

finally 抛出的异常会覆盖 try 和 catch 抛出的异常

try、catch、finally 处理范围

  • try：资源初始化、逻辑处理、抛出异常。
  • catch：异常处理、抛出异常、流程重试。
  • finally：释放资源。

已查异常和未查异常

  • 已查异常（Checked Exception）：可恢复的异常。
  • 未查异常（Unchecked Exception）：程序错误，开发者应编程处理。

接口升级

  • 区分公开接口与发布接口。
  • 重构非发布接口。
  • 谨慎声明发布接口。
  • 不要改变发布接口。

异常处理等级

  • 等级 0：未定义

HTTP 200，return code 0，接口功能是否正常不确定。

  • 等级 1：错误报告

HTTP 200/520，接口失败时返回具体错误码。

  • 等级 2：状态恢复

错误处理、资源释放。

  • 等级 3：行为恢复

异常时执行备用逻辑。

异常设计

  • 异常名称用异常内容表达，比如 NotFoundException。
  • 低级异常转抛成高级异常。
  • 同构异常：接口抛出父异常，使接口定义统一。
  • 已查异常不处理时，转抛为未查异常。
  • 通道异常、异常包装：回调函数使用未查异常 TunnelingException 封装已查异常。
  • 聪明异常：使用异常码区分同一种类的异常。

异常的终止与继续

  • 终止：结束逻辑，抛出当前层次异常。

  • 继续：记录异常，并继续处理。

异常处理的坏味道

  • 返回码代替异常。
  • 忽略已查异常。
  • 捕获 Throwable 跳过异常（比如空指针异常等）。
  • 程序最外层没有捕获所有异常。
  • 异常处理只记录日志。
  • try 语句嵌套。
  • 重试代码写在 catch 块。
  • 资源释放没有写在 finally 块。

孙杨抗检事件

发表于 2020-03-23 更新于 2026-07-30 分类于 生活
本文字数： 590 阅读时长 ≈ 1 分钟

背景

【2018 年】

  • 孙杨质疑兴奋剂检测程序不合规。
  • 电话咨询领导后，在世界反兴奋剂机构人员默许下，破坏已取样的血液。
  • 国际泳联裁决孙杨行为合法。

【2019 年】

  • 世界反兴奋剂机构上诉至国际体育仲裁法庭。
  • 国际体育仲裁法庭裁决孙杨行为不合法，禁赛八年。

分析

【历史兴奋剂检测】

  • 6000 次检测无异常。
  • 事件两天前检测无异常。

【孙杨黑历史】

  • 13 年多次无证驾驶被刑拘（个人品德问题）。
  • 14 年被检测兴奋剂阳性（孙杨团队业务问题，国际泳联错误禁止心脏病药品）。
  • 16 年里约奥运肘击巴西女运动员（个人品德问题）。
  • 18 年 8 月雅加达亚运会穿违规领奖服（个人品德问题）。
  • 18 年 9 月破坏血样（复杂事件，存在国际检测组织下套、保护血样不被掉包等可能性）。

【社会背景】

  • 中美贸易战。
  • 18 年金融危机。
  • 中国威胁论。
  • 中国兴奋剂检测机构弄虚作假严重，不被国际信任。
  • 中国体育团队兴奋剂使用严重，不被国际信任。
  • 种族歧视：国际体育仲裁法庭和世界反兴奋剂机构对有色人种的检查次数明显偏多且更严格。

结论

  • 孙杨个人品德存在问题（与本事件无关）。
  • 孙杨在兴奋剂检测过程中的行为不合规。

引申

  • 国家间的敌对与歧视是普遍存在的。
  • 种族间的敌对与歧视是普遍存在的。
  • 中国较弱的法治意识与国外较强的法治意识存在矛盾。
  • 弱法治意识导致社会特权阶级无法被有效管控，无序的事务处理方式不被国际接纳。
  • 强法治意识导致社会特权阶级垄断法律武器，多数人的法律偏向被掩盖，形成阶级矛盾。

广义相对论

发表于 2020-03-23 更新于 2026-07-30 分类于 学习
本文字数： 241 阅读时长 ≈ 1 分钟

背景

  • 万有引力定律存在误差。

假设

  • 等效原理

引力与惯性力没有区别。

  • 广义相对性原理

一切物理定律在所有参考系中均等效。

推论

引力场方程

  • 定义
  • 含义

质能导致时空扭曲，扭曲的时空又引导物质运动。

本质

  • 万有引力定律是错误的，它只是一种经验主义结论，存在误差。
  • 爱因斯坦借助洛伦兹变换和张量等数学工具，推导出了引力场的表达式。

狭义相对论

发表于 2020-03-23 更新于 2026-07-30 分类于 学习
本文字数： 590 阅读时长 ≈ 1 分钟

背景

  • 洛伦兹变换与伽利略变换不相符

洛伦兹变换由麦克斯韦方程组等电磁理论推导得出，伽利略变换则由经验猜测得出。

  • 洛伦兹变换符合现实

洛伦兹变换符合现实，伽利略变换只在低速场景下近似成立。

  • 光速不变

不同方向、不同参考系下，光速的测量结果均保持不变。

假设

  • 狭义相对性原理

一切物理定律（除引力外）在所有惯性系中均等效，符合洛伦兹变换。

  • 光速不变原理

光在真空中始终以确定的速度 $c$ 传播，其大小与光源的运动状态无关。

推论

相对长度

  • 定义
  • 含义

运动方向上，物体的长度变短。

相对时间间隔

  • 定义
  • 含义

运动方向上，物体的事件耗时相对变大。

相对速度

  • 定义
  • 含义

物体的相对速度符合洛伦兹变换，而非简单的速度叠加。

相对质量

  • 定义
  • 含义

物体的相对质量符合洛伦兹变换。

质能方程

  • 定义
  • 含义

质量是能量的一种表现形式。

本质

  • 简单的速度叠加是错误的，它只是一种经验主义结论。
  • 洛伦兹通过数学公式推导出了真实的物质逻辑关系。
  • 光速不变的深层原因，目前的科技水平暂时无法解析。

宇称不守恒

发表于 2020-03-23 更新于 2026-07-30 分类于 学习
本文字数： 141 阅读时长 ≈ 1 分钟

背景

  • θ 粒子与 τ 粒子的自旋、质量、寿命、电荷等性质完全相同。
  • θ 粒子衰变时产生 2 个 π 介子。
  • τ 粒子衰变时产生 3 个 π 介子。
  • θ 与 τ 粒子的宇称相反。

假设

  • 若宇称守恒，则 θ 与 τ 不是同一粒子。
  • 若宇称不守恒，则 θ 与 τ 是同一粒子的不同宇称状态。

论据

  • β 衰变在不同旋转方向上的衰变产物方向表明：宇称并不守恒。
